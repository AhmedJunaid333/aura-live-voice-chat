# MOMENTS REPORTS SPECIFICATION

## 1. Abuse Report Categories & Escalation

| Report Reason Category | Default Action Triggered | Safety Escalation |
| :--- | :--- | :--- |
| **SPAM_PROMOTION** | Trigger `RESTRICTED` Status | Trust & Safety Escalation |
| **HARASSMENT_ABUSE** | Flag for Moderator Review | Security Case Created |
| **SEXUAL_CONTENT** | Immediate Post Removal | Regional Safety Audit |
